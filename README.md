# AI-Assisted SDLC Framework

This repository contains a source-controlled delivery framework for Salesforce and nCino
work, from intake through production support handoff.

- Team walkthrough: `sdlc-copilot/README.html`
- Repository documentation: `sdlc-copilot/README.md`
- Role-based starting guide: `sdlc-copilot/docs/start-here.md`
- Skill registry: `sdlc-copilot/SKILLS.md`

Run `bash sdlc-copilot/scripts/validate-skills.sh` before opening a pull request.
